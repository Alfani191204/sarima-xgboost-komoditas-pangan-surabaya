# sarima-xgboost-komoditas-pangan-surabaya
Perbandingan metode SARIMA dan XGBoost dalam melakukan peramalan harga komoditas pangan di Surabaya Komoditas yang digunakan meliputi Cabai Merah Keriting, Bawang Merah, dan Beras Premium. Analisis mencakup eksplorasi data, pengujian stasioneritas, pemodelan, serta evaluasi hasil peramalan untuk mengetahui metode yang memberikan performa terbaik.
